# NVIDIA Nemotron Model Integration & Handoff Guide

## Overview

FashionPulse AI acts as the upstream quantitative intelligence layer for downstream NVIDIA Nemotron models (such as `nvidia/nemotron-4-340b-instruct` or NIM microservices).

Rather than calling an unconfigured model or simulating fake completions, the system implements a strict, pluggable boundary. When `NEMOTRON_ENDPOINT_URL` is absent, the dashboard and API explicitly state `"Nemotron not configured"` and allow previewing the exact typed payload.

## 2. Connecting a Live Nemotron Endpoint

Once your university instructor or enterprise provider gives you access to a hosted NVIDIA NIM or inference endpoint:

1. Update your `.env` file:
   ```bash
   NEMOTRON_ENDPOINT_URL=https://integrate.api.nvidia.com/v1/chat/completions
   NEMOTRON_API_KEY=nvapi-your_api_key_here
   NEMOTRON_MODEL_NAME=nvidia/nemotron-4-340b-instruct
   ```
2. The adapter `app.integrations.nemotron.NemotronServiceAdapter` will immediately route live requests to your endpoint.
3. Every dispatch attempt is recorded in the `nemotron_handoffs` table with timestamp, HTTP status code, and response summary.
